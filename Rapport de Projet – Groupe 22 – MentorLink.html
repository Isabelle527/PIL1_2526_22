2. Mode de Fonctionnement Interne

Le groupe 22 est constitué de sept membres. Compte tenu de la compréhension encore limitée de la majorité des membres concernant certaines notions nécessaires à la réalisation du projet, nous avons dans un premier temps consacré du temps à la documentation et à l'apprentissage des outils et technologies indispensables à la mise en œuvre de notre application web.

À l'issue de cette phase de préparation, nous nous sommes réunis afin d'organiser le travail et de répartir les différentes tâches. Pour optimiser l'avancement du projet, nous avons choisi de constituer deux équipes distinctes :

  • Équipe 1 – Conception et développement des interfaces utilisateur ainsi que conception de la base de données.

Après la phase de répartition des tâches, chaque équipe a travaillé sur les missions qui lui avaient été confiées. Une fois les premières réalisations terminées, les travaux ont été mis en commun afin de procéder à leur intégration. L'absence de maquette détaillée a parfois entraîné certaines divergences concernant l'apparence et l'organisation des interfaces. Les pages conçues par l'équipe chargée de l'interface ont ensuite été transmises à l'équipe responsable de la structure du projet afin d'être intégrées à l'architecture Django. Après cette étape d'intégration, l'ensemble du groupe s'est concentré sur l'implémentation des fonctionnalités prévues dans le cahier des charges.

Tout au long du projet, les échanges se sont essentiellement effectués à travers des discussions en ligne. 3. Conception du Projet

3.1 Présentation générale

MentorLink est une plateforme web développée avec le framework Django permettant la mise en relation entre mentors et mentorés. L'application offre la gestion des comptes utilisateurs, la recherche de profils, la publication de contenus, ainsi qu'un système de messagerie interne.

3.2 Structure générale des fichiers Python

L'architecture Django du projet MentorLink est structurée autour de fichiers Python clés répartis dans les modules principaux :

Fichiers de configuration de base

manage.py              # Point d'entrée principal pour exécuter les commandes Django
populate_db.py         # Script Python d'injection de données initiales dans la base
apply_migrations.py    # Script d'application automatisée des migrations
fix_and_migrate.py     # Script de résolution des conflits et de migration
run_migration.py       # Script d'exécution des fichiers de migration de l'application

Fichiers Python du module « config »

config/settings.py # Configuration centrale du projet (applications, base de données, middlewares) config/urls.py # Registre et aiguillage des routes URL principales du projet config/wsgi.py # Point d'entrée pour les serveurs web compatibles WSGI config/asgi.py # Point d'entrée pour les serveurs web asynchrones compatibles ASGI

3.3 Application « comptes »

Ce module gère les utilisateurs, leurs profils ainsi que les annonces de mentorat :

  • comptes/models.py : Définit la structure des tables via les modèles Profile et MentoratPost.
  • comptes/views.py : Contient la logique métier pour l'inscription, l'authentification, la recherche et le tableau de bord.
  • comptes/urls.py: Gère le routage des requêtes HTTP spécifiques à la gestion des comptes.
  • comptes/forms.py: Formulaires sécurisés pour la saisie et la modification des profils.
  • comptes/admin.py : Déclaration et configuration des modèles dans l'interface d'administration Django.

3.4 Application « messageries »

Ce module assure la communication interne et les échanges sécurisés entre les utilisateurs :

  • messageries/models.py: Structure des tables via les modèles Conversation,Message et ContactMessage.
  • messageries/views.py : Implémente la logique d'envoi de messages, de création de salons et de suivi des historiques.
  • messageries/urls.py : Cartographie les chemins d'accès pour l'accès aux boîtes de réception et fils de discussion.

3.5 Architecture MVT

Le projet MentorLink respecte scrupuleusement l'architecture MVT (Model-View-Template) imposée par Django. La répartition des responsabilités à travers ces différents fichiers Python garantit une maintenance simplifiée, une lisibilité accrue du code source et une excellente évolutivité pour les futurs modules de la plateforme.

4. Instructions de Déploiement

Prérequis

Avant de lancer l'application, assurez-vous d'avoir installé :

  • Python 3.10 ou une version plus récente
  • pip3 (gestionnaire de paquets Python)
  • Git
  • Un navigateur web moderne

Vérification de Python

Sous Linux :

python3 --version

Sous Windows :

python --version

Si Python n'est pas installé, téléchargez-le depuis : https://www.python.org/downloads/

Vérification et installation de pip3

pip3 --version

Si pip3 n'est pas installé (Linux) :

sudo apt update
sudo apt install python3-pip

Sous Windows, pip est inclus avec Python. Pour le mettre à jour :

python -m pip install --upgrade pip

Vérification de Git

git --version

Si Git n'est pas installé (Linux) :

sudo apt install git

Sous Windows : https://git-scm.com/downloads

Installation du module venv (Linux uniquement)

sudo apt install python3-venv

Récupération du projet

git clone https://github.com/Isabelle527/PIL1_2526_22.git
cd PIL1_2526_22

Création et activation de l'environnement virtuel

Sous Linux :

python3 -m venv venv
source venv/bin/activate

Sous Windows :

python -m venv venv
venv\Scripts\activate

Une fois activé, le terminal affiche (venv) en début de ligne.

Installation des dépendances

pip install -r requirements.txt

Ou avec pip3 si nécessaire :

pip3 install -r requirements.txt

Configuration des variables d'environnement

Si le projet contient un fichier .env.example, le copier :

cp .env.example .env

Puis éditer .env pour y renseigner les valeurs propres à votre environnement (clé secrète, base de données, etc.).

Initialisation de la base de données

python manage.py migrate

Ou sous Linux :

python3 manage.py migrate

Chargement des données initiales (optionnel)

python manage.py loaddata nom_du_fichier.json

Collecte des fichiers statiques (optionnel)

python manage.py collectstatic

Création d'un compte administrateur (optionnel)

python manage.py createsuperuser

Suivre les instructions pour définir un nom d'utilisateur, une adresse e-mail et un mot de passe.

Lancement de l'application

python manage.py runserver

Ouvrir l'adresse suivante dans un navigateur :

http://127.0.0.1:8000/

L'interface d'administration est accessible à :

http://127.0.0.1:8000/admin/

Arrêt du serveur

Ctrl + C

Mise à jour du projet

git pull origin main
python manage.py migrate

5. Manuel d'Utilisation

5.1 Accès à la plateforme

Une fois le serveur lancé, ouvrez un navigateur et accédez à http://127.0.0.1:8000/. La page d'accueil de MentorLink s'affiche.

5.2 Création d'un compte

  1. Cliquez sur le bouton S'inscrire depuis la page d'accueil.
  2. Remplissez le formulaire d'inscription (nom d'utilisateur, adresse e-mail, mot de passe).
  3. Validez en cliquant sur Créer mon compte.
  4. Vous êtes redirigé vers votre tableau de bord personnel.

5.3 Connexion

  1. Cliquez sur Se connecter.
  2. Saisissez votre nom d'utilisateur et votre mot de passe.
  3. Cliquez sur Connexion pour accéder à votre espace.

5.4 Compléter son profil

  1. Accédez à la section Mon profil depuis le menu de navigation.
  2. Renseignez vos informations : compétences, domaines d'expertise, disponibilités.
  3. Précisez votre rôle : Mentor (vous souhaitez partager vos connaissances) ou Mentoré (vous recherchez un accompagnement).
  4. Enregistrez les modifications.

5.5 Recherche de profils

  1. Utilisez la barre de recherche ou accédez à la section Explorer.
  2. Filtrez les résultats par domaine, compétence ou rôle (mentor / mentoré).
  3. Consultez les profils qui correspondent à votre recherche.

5.6 Messagerie interne

  1. Depuis le profil d'un utilisateur, cliquez sur Envoyer un message.
  2. Une conversation est créée et accessible depuis la section Messagerie.
  3. Répondez aux messages reçus directement dans le fil de discussion.

5.7 Publication d'annonces de mentorat

  1. Accédez à la section Mes annonces.
  2. Cliquez sur Nouvelle annonce et décrivez votre offre ou demande de mentorat.
  3. Publiez l'annonce pour qu'elle soit visible par les autres utilisateurs.

5.8 Interface d'administration

Réservée au super-utilisateur créé lors du déploiement, l'interface d'administration est accessible à :

http://127.0.0.1:8000/admin/

Elle permet de gérer l'ensemble des utilisateurs, profils, annonces et messages de la plateforme.

5.9 Déconnexion

Cliquez sur Se déconnecter depuis le menu de navigation pour mettre fin à votre session.
